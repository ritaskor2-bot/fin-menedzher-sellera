# Фин менеджер селлера: рабочий набор

Шаблон для ведения финансов селлера на Wildberries и Ozon. Внутри — только правила и заготовки, без данных конкретного клиента. Кладёшь файлы нового селлера в `input/`, запускаешь скрипт, получаешь планы и отчёты.

## Структура

```
ФИН менеджер селлера/
├── README.md          ← краткое описание
├── GUIDE.md      ← пошагово: от выгрузок до отчётов
├── rules/             ← правила: что и как считать
│   ├── 01-weekly.md           еженедельный разбор (P&L, ДДС, остатки, группы артикулов)
│   ├── 02-daily-ozon.md       дневной отчёт по Ozon: заказы, воронка, рекомендации
│   └── 03-formulas.md         формулы, пороги, нормативы
├── scripts/           ← расчёты
│   ├── lib/xlsx.js            общий модуль записи xlsx
│   ├── make-templates.js      создаёт пустые планы WB и Ozon
│   ├── make-orders-plan.js    CSV с планом в заказах → json
│   ├── build-cashflow.js      платёжный календарь + ДДС
│   └── ozon-daily-digest.js   дневной дайджест по Ozon
├── templates/         ← пустые планы с формулами (создаются скриптом)
└── input/             ← сюда кладёшь файлы селлера
```

## Структура агентов

Правило «главный агент + субагенты» реализовано в `.opencode/agents/`.

| Файл | Роль | Режим | Что делает |
|---|---|---|---|
| `fin-menedzher-sellera.md` | главный | `primary` | принимает задачу, выбирает субагента по таблице маршрутизации, собирает итог |
| `ozon-daily.md` | субагент | `subagent` | дневной отчёт по Ozon: заказы против плана, топ-17, рекомендации |
| `wb-weekly.md` | субагент | `subagent` | недельный разбор WB: P&L, группы, остатки, досыл |
| `cashflow.md` | субагент | `subagent` | платёжный календарь и ДДС: поступления с лагами, закупка, разрывы |
| `plan-month.md` | субагент | `subagent` | план на месяц по WB и Ozon: прогноз, остатки, заказ на дошив |

**Как это устроено:**

1. **Главный агент** — точка входа. У него в теле есть таблица «Кого звать»: запрос → субагент. Он же отвечает за формат итога и соблюдение границ.
2. **Субагенты** — узкие: у каждого один тип задачи, свои источники, свой скрипт и свой файл правил в `rules/`.
3. **Правила субагента** лежат в его файле в `.opencode/agents/` — роль, источники, команда запуска, пороги. Детали расчёта — в `rules/`. Коротко: агент отвечает «что делать», `rules/` — «как считать».
4. **Права** — у всех агентов удаление и перемещение файлов требуют подтверждения (`effect: ask`).
5. **Общие границы** — в `AGENTS.md` в корне: обращение на «ты», формат ответа, запреты.

**Как вызвать:**

- Переключиться на главного в селекторе агентов → «Фин менеджер селлера».
- Или попросить точечно: «через ozon-daily посчитай вчерашний день» — главный вызовет нужного.
- Субагенты не выбираются как основной агент: они работают под главным.

**Как добавить нового субагента:**

1. Создать файл в `.opencode/agents/<имя>.md` с frontmatter:
   ```
   ---
   description: когда использовать (это видит главный при выборе)
   mode: subagent
   permissions:
     - action: shell
       resource: "rm *"
       effect: ask
   ---
   ```
2. В теле описать: источники, команду запуска, что показывать, пороги, формат ответа.
3. Добавить строку в таблицу «Кого звать» в `fin-menedzher-sellera.md`.
4. Если нужны новые правила расчёта — файл в `rules/`.
5. Перезапустить OpenCode, чтобы агент появился в списке.

## Быстрый старт

1. **Создай шаблоны планов:**
   ```
   node scripts/make-templates.js
   ```
   Появятся `templates/plan-wb.xlsx` и `templates/plan-ozon.xlsx` — только шапки и формулы, строки пустые.

2. **Заполни исходные данные** в `input/`:
   - выгрузка WB: `export_report_product*.xlsx` (заказы, продано, остатки, % выкупа);
   - Ozon: `продажи и выручка*.xlsx`, `заказы и % выкупа*.xlsx`, `остатки.xlsx`;
   - дневной отчёт Ozon: `optiflou-rnp-*.xlsx`.

3. **Собери планы:**
   - `node scripts/make-templates.js` → пустые планы;
   - перенеси данные в планы вручную или допиши загрузчик под свою выгрузку (структура столбцов описана в `rules/03-formulas.md`).

4. **Посчитай деньги:**
   ```
   node scripts/build-cashflow.js --oz-sales 16000000 --wb-sales 4000000 --oz-rate 0.52 --wb-rate 0.35 --purchase 3000000 --opening 0 --out output/кассовый-план.xlsx
   ```

5. **Дневной отчёт:**
   ```
   node scripts/ozon-daily-digest.js --file input/optiflou-rnp-2026-12-01-2026-12-01.xlsx --plan input/plan-ozon-orders.json
   ```

## Главные правила

- **Прибыль** — чистая, после постоянных расходов.
- **Выручка** — до СПП, если не сказано иное.
- **Остатки** — только из кабинетов или API площадок, не из аналитических сервисов.
- **Налоги и юрлицо** — уточнять у бухгалтера, в шаблоне их нет.
- **Данные клиента** — не выгружать в сторонние сервисы и нейросети без разрешения.

## Что нужно адаптировать под нового селлера

| Что | Где |
|---|---|
| Доли выплат площадок | `build-cashflow.js`, параметры `--oz-rate`, `--wb-rate` |
| Категории «дошиваем / не дошиваем» | `rules/03-formulas.md`, раздел «Подсорт» |
| Пороги (СПП, выкуп, ДРР) | `rules/03-formulas.md` |
| Бот и чат для отчётов | `ozon-daily-digest.js`, переменные окружения `TG_TOKEN`, `TG_CHAT` |
