Фин менеджер селлера

Агентская система финансового управления для селлеров Wildberries и Ozon · версия 1.0 · 23.11.2026

Проблема

Селлер видит выручку в кабинете, но не видит денег: когда придут выплаты, хватит ли их на следующую партию и где закончится товар.

  • Платежи площадок приходят с разными лагами: Ozon — через неделю, WB — через пять. Кассовый разрыв обнаруживается, когда деньги уже нужны.
  • Остатки, продажи и закупки живут в разных файлах; план продаж не сверяется с остатком и деньгами.
  • Итог: замороженные в неликвиде деньги, дефицит на росте, штрафы и упущенные продажи.

Пользователь

  • Финансовый аналитик на аутсорсинге — ведёт нескольких селлеров, собирает планы и отчёты вручную.
  • Селлер малого бизнеса — собственник, который принимает решения по закупке и цене.
  • Финансовый менеджер в штате — нужен повторяемый процесс вместо разовых таблиц.
Уровень подготовки: уверенный Excel, базовое понимание юнит-экономики. Программирование не требуется — запуск одной командой.

Основная функция

Вход
Выгрузки WB и Ozon: продажи, заказы, остатки, дневной отчёт. Параметры: доли выплат, лаги, рост, минимальная партия.
→
Выход
План по артикулам, календарь поступлений и ДДС, дневной дайджест, недельный разбор.
ПланированиеПрогноз продаж от факта, наложение остатков, план в штуках, рублях и заказах в день
ДеньгиПоступления по неделям с лагами площадок, закупка по себестоимости, остаток на конец, поиск разрывов
КонтрольВыполнение плана по заказам, воронка (показы → карточка → корзина → заказ), ДРР, конверсии
РешенияЧто дозаказать, что распродать, где поднять цену, где снизить рекламу
ИнструментыСкрипты Node.js, Excel-шаблоны с формулами, Telegram-бот, HTML/PDF-отчёты

Формат результата

  • Excel-план — лист с артикулами, формулами и параметрами: меняешь рост или остаток, всё пересчитывается.
  • Excel-ДДС — недели, поступления по площадкам, закупка, остаток, красные недели разрыва.
  • Дневной дайджест — 10–15 строк в Telegram: заказы против плана, топ-17, что делать.
  • Недельный отчёт — markdown: главное, площадки, группы артикулов, рекомендации, источники.
  • Визуальный отчёт — HTML/PDF для показа собственнику или клиенту.

Минимальный функционал (MVP)

В первой версии
  • Главный агент + 4 субагента: план, деньги, день, неделя.
  • 2 шаблона планов с формулами (WB и Ozon).
  • ДДС и платёжный календарь с лагами.
  • Дневной дайджест с отправкой в Telegram.
  • 3 файла правил и инструкция запуска.
Дальше
  • Автозагрузка выгрузок через API площадок.
  • Несколько клиентов в одном интерфейсе.
  • Веб-дашборд вместо Excel.
  • Сценарное моделирование: цена, реклама, закупка.
  • Автоматический недельный отчёт по расписанию.

Технологии

ЯзыкNode.js 24, CommonJS; PowerShell для запуска Excel и печати PDF
ExcelГенерация .xlsx через jszip, формулы в самих файлах, без внешних библиотек
ДанныеРазбор .xlsx напрямую из XML; CSV → JSON для плана в заказах
ОтчётыMarkdown, HTML + CSS без зависимостей, PDF через Chrome headless
ИнтеграцииTelegram Bot API (дайджест), Excel COM (работа с готовыми файлами)
АгентыOpenCode: YAML-frontmatter, mode: primary / subagent, права на файловые операции
Демонстрационное описание: клиентских данных нет. Структура и команды соответствуют пакету «ФИН менеджер селлера».
