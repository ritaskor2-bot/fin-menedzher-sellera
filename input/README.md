# input — данные селлера

Сюда кладутся исходные выгрузки. Имена файлов могут быть любыми, важно содержимое.

## Что нужно

| Файл | Откуда | Обязательно |
|---|---|---|
| Выгрузка WB по товарам (`export_report_product*.xlsx`) | Кабинет WB → Аналитика → Отчёт по товарам | Для плана WB |
| Продажи Ozon по товарам (`продажи и выручка*.xlsx`) | Ozon → Аналитика → Отчёты | Для плана Ozon |
| Заказы и % выкупа Ozon (`заказы и % выкупа*.xlsx`) | Ozon → Аналитика | Для плана Ozon |
| Остатки (`остатки.xlsx`) | Кабинет Ozon / WB, API | Для наложения остатков |
| Дневной отчёт Ozon (`optiflou-rnp*.xlsx`) | Ozon → Отчёты → по дням | Для дневного дайджеста |

## Что проверить перед загрузкой

1. Период выгрузки — тот, который считаем. Записать его в название файла или в заметку.
2. Все артикулы и размеры на месте: сумма по строкам = итог отчёта.
3. Остатки — из кабинета, не из стороннего сервиса аналитики.
4. Нет личных данных покупателей (ФИО, адреса) — они не нужны.

## Чего здесь быть не должно

- Паролей, токенов, доступов.
- Персональных данных покупателей.
- Файлов других клиентов.

## После загрузки

1. `node scripts/make-templates.js` — создать пустые планы.
2. Заполнить планы (A–F, M) или дописать загрузчик под свою выгрузку.
3. `node scripts/build-cashflow.js ...` — деньги.
4. `node scripts/ozon-daily-digest.js --file input/<дневной файл>` — день.
