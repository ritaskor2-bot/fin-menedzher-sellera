# 03. Формулы, пороги, нормативы

## Выручка и цена

- **Выручка до СПП** — сумма продаж по цене до скидки площадки. Основная база для планов и маржи.
- **Выручка после СПП** — фактическая цена для покупателя.
- **Цена единицы до СПП** = сумма заказов в рублях ÷ заказано, шт (WB) или выручка до СПП ÷ доставлено (Ozon).
- **СПП, п.п.** — разница между ценой до и после скидки площадки.

## Маржа и прибыль

```
Маржинальная прибыль = выручка до СПП
  − себестоимость
  − комиссия площадки
  − логистика
  − хранение
  − эквайринг
  − реклама
  − прочие переменные

Чистая прибыль = маржинальная прибыль − постоянные расходы
Маржинальность, % = маржинальная прибыль ÷ выручка до СПП × 100
ДРР, % = реклама ÷ выручка до СПП × 100
```

Ориентиры: маржинальность не ниже 18%, цель 20%; ДРР сравнивать с маржинальностью, а не с «нормой по рынку».

## Выкупы и возвраты

```
Выкуп, % = выкупы ÷ заказы × 100
Возвраты, % = возвраты ÷ доставлено × 100
```

Норма зависит от категории: в одежде выкуп 10–30% и возвраты 15–30% — обычное дело, если не растут.

## Остатки и покрытие

```
Покрытие, дней = (остаток на площадке + ФФ + в пути) ÷ скорость заказов за последние 7 дней
Скорость, шт/день = заказы за 7 дней ÷ 7
```

- **Точка дозаказа** = цикл поставки + страховой запас.
- **Максимум запаса** — верхняя граница после прихода партии.
- **Оборачиваемость** = остаток ÷ скорость.

## Подсорт: что дошиваем

Категории делятся на две группы:

1. **Дошиваем** — планируем продажи без ограничения остатком, потому что товар придёт.
2. **Распродажа остатка** — план ограничен остатком: продаём, пока есть запас, дальше ноль.

Правило: план на период ≤ остаток + подтверждённые приходы. Если товар не придёт в периоде — считаем только остаток.

```
Доступно = остаток − (прогноз периода − уже продано)
План = min(прогноз × рост; доступно)   — для распродажи
План = прогноз × рост                   — для подсорта
```

Минимальная партия и срок заказа задаются параметрами: например, партия кратна 200 шт, срок 2 месяца. Заказ считается на горизонт (2 месяца), а не на текущий месяц.

## Деньги

```
Поступления площадки = продажи недели × доля выплат
Доля выплат = к перечислению ÷ выручка (по факту) либо задаётся вручную
Лаг: WB — до 5 недель, Ozon — 1 неделя
Остаток на конец = остаток на начало + поступления − платежи
```

Кассовый разрыв — неделя, где остаток уходит в минус после обязательных платежей.

## Пороги мониторинга

| Показатель | Предупреждение | Критично |
|---|---|---|
| Скорость заказов к средней за 2 недели | ±15% | ±20% |
| Цена для покупателя | ±5% | ±8% |
| СПП | ±3 п.п. | ±6 п.п. |
| Выкуп | ±5 п.п. | ±8 п.п. или ниже 75% |
| Комиссия или логистика | ±2 п.п. | — |
| Покрытие на площадке | < 10 дней при товаре на ФФ | 0 дней |

## Группы артикулов

| Группа | Признак |
|---|---|
| 1. Двигатели | Растут, прибыльные, обеспечивают выручку |
| 2. Прибыльные, но падают | Маржа плюс, заказы падают >10% |
| 3. Минус из-за рекламы | ДРР выше маржинальности |
| 4. Минус из-за логистики / выкупа | Логистика и возвраты съедают маржу |
| 5. Неликвид | Оборот больше 90 дней или продажи ~0 |
| 6. Нет остатка | Продаж нет, товара нет |
| 7. Архив | Снят с продажи |

## Что считать «дошивом» в заказе

```
Объём заказа = скорость × (цикл + страховой запас + дни до следующего заказа)
              − остатки − товар в пути
```

Округлить вверх до минимальной партии. Если объём больше максимума запаса — разделить партию или сдвинуть приход.
